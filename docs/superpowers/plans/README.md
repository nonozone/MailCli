# Execution Plan Archive

This directory keeps dated execution plans that were useful while specific
implementation passes were in progress.

Treat these files as historical records by default. An unchecked box in an old
plan file is not an active project TODO unless the plan is explicitly linked
from a current roadmap item or an open GitHub issue.

Current sources of truth:

- [Next Development Roadmap](../../en/project/next-roadmap.md)
- [下一阶段开发路线](../../zh-CN/project/next-roadmap.md)
- [GitHub Backlog Drafts](../../en/project/github-backlog.md)
- [GitHub Backlog 草案](../../zh-CN/project/github-backlog.md)
- [Open GitHub issues](https://github.com/nonozone/MailCli/issues)

Audit rule:

- Use dated plan files to understand why a previous implementation pass was
  shaped a certain way.
- Use the roadmap and open GitHub issues to decide what is still active.
- When reactivating an old plan, open or link a GitHub issue and update that
  issue with the current acceptance criteria instead of editing every old
  checklist.
